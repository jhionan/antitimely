---
description: How to manage the work timer (Antitimely)
---

You can manage the user's work sessions using the `antitimely` tool.

1. **Check current status**
// turbo
```bash
/Users/rian/.gemini/antigravity/scratch/antitimely/antitimely status
```

2. **Start or resume a session**
// turbo
```bash
/Users/rian/.gemini/antigravity/scratch/antitimely/antitimely start
```

3. **Pause the current session**
// turbo
```bash
/Users/rian/.gemini/antigravity/scratch/antitimely/antitimely pause
```

4. **Generate a report**
// turbo
```bash
/Users/rian/.gemini/antigravity/scratch/antitimely/antitimely report
```

5. **Conclude the day**
// turbo
```bash
/Users/rian/.gemini/antigravity/scratch/antitimely/antitimely conclude
```
